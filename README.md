# AI 影片剪輯最優方案診斷器（AI Video Workflow Advisor）

> 免費公開互動工具：點選你的影片類型、素材現況、特效需求與優先取向，30 秒診斷最適合你的 AI 影片剪輯處理路線！

🔗 **線上直接使用（GitHub Pages）**：https://kevintsai1202.github.io/ai-video-advisor/

---

## 核心特色

- **4 維度即時評分診斷**：涵蓋影片類型、實拍／錄屏素材現況、3D／數據圖表／動態模糊／漏光濾鏡／AI 配音／橫直雙版／XML 精修等進階條件與優先取向。
- **五大 AI 剪輯處理路線即時比較**：
  1. **Hyperframes（單檔 HTML/GSAP）＋ FFmpeg 封裝**
  2. **Remotion（React/TSX 多核併發）＋ FFmpeg 封裝**
  3. **Playwright 自動操作錄製 × MCP 智能控剪（剪輯軟體直出）**
  4. **實拍原片 × MCP 智能控剪（以文剪片＋剪輯軟體直出）**
  5. **雙路線黃金混搭（程式化 3D/圖表片段 × MCP 剪輯軟體組裝直出）**
- **行動級輸出**：自動產生專屬執行 SOP、避坑警示、終端機起手指令、可直接貼給 AI Agent 的開工 Prompt。
- **零追蹤、零相依**：純單檔靜態 HTML（所有計算於瀏覽器本機完成），支援 **🔗 分享結果網址**、**📋 匯出 Markdown** 與 **🖨 列印 PDF**。

## 本機直接使用

下載 `index.html` 後以任意現代瀏覽器開啟即可使用，無需安裝任何套件或啟動伺服器。
